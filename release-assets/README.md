# 誤差貯金 リリース素材

このフォルダには、リリース前の確認とストア提出に使うローカル生成素材をまとめています。

## スクリーンショット

- `screenshots/01-home.png`: 守れたお金が、ひと目でわかる
- `screenshots/02-record.png`: 使わなかった金額をすぐ記録
- `screenshots/03-growth.png`: 小さな誤差が、成長として見える
- `screenshots/04-stats.png`: 月ごとの積み上がりを確認
- `screenshots/contact-sheet.png`: 4枚まとめて確認するための一覧画像

## 外部確認が必要なもの

- 実際の公開URL
- プライバシーポリシーURL
- サポートURL
- 実機でのPWAインストール挙動
- ストア提出先の最新スクリーンショットサイズ基準
- ストアアカウント上での申請、審査、公開
