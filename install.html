誤差貯金

ホーム画面に追加する

ストアから入れなくても、スマホのホーム画面に追加してアプリのように使えます。

まずアプリを開く

公開URLをスマートフォンのブラウザで開いてください。

誤差貯金を開く

iPhoneの場合

  1. Safariで誤差貯金を開きます。
  2. 画面下の共有ボタンを押します。
  3. 「ホーム画面に追加」を選びます。
  4. 名前が「誤差貯金」になっていることを確認して「追加」を押します。
  5. ホーム画面のアイコンから起動します。

Androidの場合

  1. Chromeで誤差貯金を開きます。
  2. 画面右上のメニューを押します。
  3. 「アプリをインストール」または「ホーム画面に追加」を選びます。
  4. 表示内容を確認して追加します。
  5. ホーム画面のアイコンから起動します。

追加できないとき

  • iPhoneではSafariで開いているか確認してください。
  • AndroidではChromeで開いているか確認してください。
  • 公開URLが `https://` で始まっているか確認してください。
  • 一度ページを再読み込みしてから、もう一度試してください。

データについて

現在のMVPでは、記録した金額やメモはお使いのブラウザ内に保存されます。端末やブラウザを変えると、保存済みデータは自動では引き継がれません。
